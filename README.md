# 循線實驗室

以 Fusion 裝配 `2627_CAR_v2` 製作嘅課堂循線模擬。MuJoCo WebAssembly 負責物理運算，Three.js 顯示車同賽道。每個瀏覽器分頁有自己嘅模擬。

## 本機使用

需要 Node.js 22.12 或以上。喺呢個資料夾執行以下命令，再開終端顯示嘅網址。

```sh
npm ci
npm run dev
```

測試正式發佈版本時，先執行 `npm run build`，再用 `npm run preview -- --host 127.0.0.1 --port 4173`。預覽網址係 [http://127.0.0.1:4173](http://127.0.0.1:4173)。

## 點樣試

右上角可以揀繁體中文或 English，同一個瀏覽器會記住上次選擇。頁首可選跟系統、淺色或深色，瀏覽器會記住選擇。畫面、對話框同 3D 賽道會同步切換。

撳「開始模擬」，課堂車基準用 P = 2、I = 0、D = 1.5、基礎速度指令 7。用「感測板」鏡頭放大車頭黑色電路板。探頭讀到黑線時，板面對應嘅燈會亮起，下面同一路會顯示原始值 1。離開黑線回到白底會熄燈，讀數變 0。選 0.5× 慢播可以睇清楚由邊一路開始偏移，再對照循線偏差、轉向修正同左右輪指令。按暫停會定格所有數值。手動支援 0.5×、1×、2×、4×，各種播速用相同嘅物理步距同車速設定。

將 P、I、D 全部歸零，或者撳「示範零增益甩線」，兩個摩打都會收到相同指令。架車喺預設賽道第一個彎會直行離開黑線，紅色軌跡標示失線路段。課堂原程式有獨立嘅失線搜線分支。模擬特別喺三個增益都為零時略過呢個分支，方便學生觀察冇轉向修正嘅結果。有任何一個非零增益時，選「原程式搜線」會按最後偏差用 3／23 或 23／3 搜線。揀「直行（關閉搜線）」可以單獨比較 PID。安裝方向以車頭向前計。預設 S1 喺左，亦可揀 S8 喺左，重現原程式註解所寫嘅排列。畫面嘅通道標示會跟住調換，改安裝或搜線設定會重新記錄。

## PID 原理同工作紙

[手動探頭實驗](https://line-follower-2627.pages.dev/#probe-lab) 可以逐個撳 S1 至 S8，黑線為 1。原始 byte 以 bit 7 至 bit 0 排列，Serial Monitor 以 S1 至 S8 排列。每撳單步就用當時選定嘅通道同增益計 10 ms；中途轉探頭會保留上一步偏差同積分。練習預設採用教材例題嘅 P = 1、I = 0.5、D = 0.005、基礎速度 10，使用自己嘅時間同 PID 記錄。重設記錄後可用同一組讀數由頭比較。

喺手動模式撳「單步 +10 ms」，會由就緒或暫停狀態向前行一個控制週期。取樣表由車頭左至右列出通道、0/1 同權重，再將當次嘅增益、上次偏差同積分代入算式，列出限幅前後嘅修正及左右輪整數指令。切換播放倍速唔會改變單步長度。暫停時改增益，新設定由下一個控制週期生效。

學生可以喺 [PID 原理](https://line-follower-2627.pages.dev/#pid-lesson) 由八路權重算偏差，逐項理解 P、I、D，再用「拆解今次 PID 修正」比較每次模擬更新嘅數值。[工作紙練習](https://line-follower-2627.pages.dev/#worksheet) 收錄中五第 5 章第 19、20 題，附原工作紙第 6 頁 PDF。第 19 題按題意用 0.10 s、保留小數，模擬控制用 0.010 s 同整數摩打指令。

## 純 P 同 PD 搖頭比較

[課堂基準](https://line-follower-2627.pages.dev/?trial=pd#simulator) 採用老師提供嘅最佳實車設定 P = 2、I = 0、車速指令 7。D 以 1.5 代表「1 點幾」。[加 P、減 D](https://line-follower-2627.pages.dev/?trial=swing#simulator) 用 P = 4、D = 0.01，純 P 試跑用 P = 4、D = 0。網站開場及三個示範都用相同左偏 15 mm 起點同 40 ms 額外指令延遲。馬達繼續依原有估算 90 ms 響應驅動 MuJoCo 輪軸。額外 40 ms 係教學比較假設，實車有待量度。可以用置中起步或 0 ms 作對照。下載嘅 Main 保留原有硬編碼啟動增益，可在車載介面輸入老師嘅實測設定。

Kp 可試 0–8、Ki 0–2、Kd 0–2。Main 按實際秒數計 D，模擬用固定 10 ms。偏差跳一格，D = 1.5 已足以令轉向修正撞到 ±8 上限。[Pololu 範例](https://www.pololu.com/docs/0J21/7.c) 用逐次偏差之差，所以增益數字使用不同單位。頭段直路量到基準、高 P 低 D、純 P 車頭角度峰對峰分別約 6.5°、15.2°、15.9°。同一圈第一次回程直路 x = −0.45 至 +0.42 m，每 10 ms 讀取實際車身朝向，分別為 3.2°、12.7°、13.2°。固定方向近鏡同最近四秒朝向圖可觀察走勢。手動 CSV 列出車身朝向（世界 +X 為 0°，逆時針為正）、發出同延遲後傳到馬達嘅指令。

## AI 試跑同殘影比較

喺手動模式揀好車、地圖同非零車速，再開「AI 試跑」。每輪都從同一起點開始，跑 24 秒模擬時間。第一輪用零增益作基準。之後由瀏覽器內嘅搜尋程式，根據之前試跑量得嘅結果選下一組 PID。每次最多比較八組。每 10 ms 保留一次車位同探頭讀數，可選 0.5×、1×、2×、3×、6× 或 12× 重播同一輪。

同時睇歷次路徑同車身殘影，就可以比較同一時間邊一組喺彎位失線。評分綜合沿線前進程度、失線比例、偏差及轉向平順度。預設賽道可量度沿環線嘅前進距離；自訂地圖容許分岔，改為計算循線覆蓋距離以減少原地兜圈得分。比較結果只適用於該次車模、路線及車速組合。「套用最佳 PID 至手動模式」可將今次最佳組合帶返去再試，亦可匯出各輪數據。

[八輪試跑範例 CSV](examples/2627_CAR_v2-PID-trials.csv) 使用原裝車、預設環線、基礎指令 10、S1 在左，同原程式搜線。表內有輪次、增益、分數、失線時間、次數、最長連續失線同循線距離。

## 畫地圖或用相片製作賽道

「繪製地圖」可以用滑鼠或手指畫線。用「相片轉 SVG」揀一張從正上方影嘅 JPG 或 PNG，相片最好先裁走背景。預覽黑線後，可以調黑白門檻、設定地圖實際闊度，再喺線上揀起點同車頭方向。「套用賽道」後，八路探頭會讀新圖。下載 SVG 可以保存或交畀同學，用相同入口重新載入。本版自訂地圖支援開放線段、分岔，所以唔自動計圈。

## 用自己嘅 Fusion 模型

建議由 Fusion 匯出整個裝配嘅 STEP（.step 或 .stp），保留可辨認嘅車輪零件名稱。喺「匯入車模」選擇檔案，確認朝上、向前方向同輪軸位置，再檢查輪徑、左右輪中心距、前置感測器距輪軸距離同感測器間距。亦可以用 STL 並指定長度單位。原裝車可用 [2627_CAR_v2.step](examples/2627_CAR_v2.step) 試匯入。

重新匯入同一架車嘅 STEP，或者保留咗完整感測板幾何嘅單一 STL，一樣可以見到八盞燈。程式會核對電路板外形、厚度、兩排共 16 粒光學元件嘅位置，再將燈放喺模型上。其他板型或簡化咗探頭嘅 STL 仍可用畫面下方嘅八路數字讀數。

模型同地圖檔案均由瀏覽器本機讀取。匯入車模會套用到目前賽道。車身碰撞、馬達同八路感測控制使用教學用雙輪差速模型，質量、慣性同摩擦仍需按實車校準。

## 模型同實車數據

- `public/models/car.json` 來自 Fusion 當時開住嘅裝配，包含車板、馬達、車輪、牛眼輪、感測板同其他可見零件嘅三角網格。部分材質為方便辨認而調色。
- CAD 輪徑 68 mm，兩輪中線相距約 181.3 mm。八路感測器橫向相隔 11.5 mm，光學元件對嘅中點喺輪軸前方約 158.8 mm。
- 原裝車嘅黑色感測板有 16 粒向地面嘅光學元件，分成八對。匯出網格冇獨立嘅板面 LED。模擬參考同尺寸廠方板圖，喺板面前緣內側約 1.3 mm、對正每對探頭加八個燈位。亮燈代表模擬探頭讀到線。實物燈色同亮滅邏輯仍要用實車核對。[Hiwonder 八路板尺寸圖](https://cdn.shopify.com/s/files/1/0084/2799/5187/files/7_4beb0901-f1a6-4413-b0fb-509308353b2a.jpg?v=1786186017)
- MuJoCo 用可自由移動嘅車身、兩個獨立輪軸、輪胎接觸同低摩擦球形支點。控制器每 10 ms 讀一次八路虛擬探頭，按黑膠帶覆蓋位置產生數碼訊號，計算 PID 轉向。物理每 2 ms 更新一次。
- 跑道黑線闊 21 mm。光學元件底部離地約 10.1 mm。模擬用五點取樣估算探頭視野，同一位置三點或以上見黑就將該路標記為見線，對應課堂板原始值 1。取樣半徑、黑白門檻、馬達反應時間（90 ms）、負載同摩擦係估算值。實車光學門檻要用實際地面及膠帶校準。[Hiwonder 八路循線板通訊及自學程序](https://wiki.hiwonder.com/projects/8-ch-Line-Follower/en/latest/docs/2.Quick_Start.html)
- Fusion 零件同課堂接線圖吻合 Hiwonder 膠軸 TT Hall 編碼摩打。依廠方規格設定 6 V、空載 150 rpm、減速比 42:1。單相讀取每輪一圈 252 脈衝，四倍頻係 1008 計數。模擬假設驅動板用四倍頻。輪徑 68 mm 時，指令 10 嘅目標約 21.2 cm/s，指令 23 約 48.7 cm/s。畫面嘅實際輪速由 MuJoCo 輪軸角速度計出。實車可量十圈編碼器總差除以十，核對實際計數模式。[Hiwonder TT 摩打規格](https://www.hiwonder.com/products/tt-motor-plastic) · [Hiwonder 馬達板與編碼器](https://wiki.hiwonder.com/projects/Ackermann-Chassis/en/latest/docs/3_Arduino_Version_formatted.html)
- 八路感測器用 I²C 地址 0x5D，讀 S1 至 S8 的數碼狀態。CAD 用 90 mm 闊嘅板，兩款外觀相似嘅廠方模組有唔同感測高度，實車型號有待確認。[Hiwonder 90 mm 感測板](https://www.hiwonder.com/products/8-channel) · [另一款八路板](https://www.hiwonder.com/products/8-channel-ir-line-follower-sensor)

## 同課堂程式嘅對照

指定嘅 `Downloads/F5_Line_Follower 2/Line_Follower_mian` 係 Wi-Fi 網頁測試。循線邏輯來自旁邊 `Downloads/F5_Line_Follower/Line_Follower_mian` 嘅完整程式，同 `LineFollowerUpload460800` 嘅 TT 診斷版對照。後者用 M3 左輪、M4 右輪，選 TT 模式 1。舊 ZIP 用 JGB37 模式 3；其 3960 計數預設用於距離換算。

[Arduino 下載區](https://line-follower-2627.pages.dev/#arduino) 包括原裝讀數範例 01_Digital_States.ino、課堂 TT 版本嘅完整 .ino、LineFollowerLearn8CH ZIP 同 MotorEncoderBoard ZIP。實車範例開機時會產生本機 Wi-Fi 密碼，用 115200 baud 開 Serial Monitor 就可以睇到。發佈前以全新 sketchbook 安裝提供嘅兩個 ZIP，使用 Espressif ESP32 Arduino core 3.3.12 及 ESP32 Dev Module 編譯成功。

感測程式庫嘅 `detect_state_all_channel_IIC` 會讀地址 0x5D 嘅寄存器 5，再將 `(raw >> i) & 1` 放入 `state_all_ch[i]`。bit 0 對應 S1，bit 7 對應 S8。課堂第 5 章工作紙記錄向車頭前望時 S1 在左、S8 在右。舊 sketch 嘅左右註解相反，公開範例嘅註解同車載網頁通道排列已按課堂安裝校正。反向安裝選項保留 library 嘅原有通道編號。

課堂板按老師提供嘅極性判斷黑線，黑色讀 1，白底讀 0。ZIP 原裝範例 `01_Digital_States.ino` 用 115200 baud，每 200 ms 由 S1 至 S8 印一次八路原始值。見到 `1 0 0 0 1 0 0 0` 即 S1、S5 黑色，另外六路白色，寄存器為 `0x11`。如果係直接寫寄存器數值 `0b10001000`（`0x88`），即 S4、S8 黑色。原裝 ZIP 嘅 I²C 註解亦寫明偵測到線時為高電平，讀取函式會逐 bit 拆出寄存器數值。原裝讀數範例亦可喺網站獨立下載。

兩份循線程式嘅 S1 至 S8 權重都係 −7、−5、−3、−1、1、3、5、7；只平均偵測到線嘅探頭。每 10 ms 更新，積分限幅 ±20，PID 修正限幅 ±8，左右輪指令取整後限於 0–23。正修正會加快左輪、減慢右輪。以車頭向前、左摩打實際驅動左輪計，S1 放左會修正返條線，S8 放左則會反向修正。模擬器保留兩種安裝選項；實車要以逐個遮探頭同左右輪接線核實。模擬將速度指令 0 定義為停車。

## 發佈到 Cloudflare Pages

初次登入執行 `npx wrangler@4 login`。已建立嘅 Pages 項目可用以下命令更新。

```sh
npm run build
npx wrangler@4 pages deploy dist --project-name line-follower-2627 --branch main
```

發佈內容係 `dist/`，包含 WASM、車模、網頁同跑道程式。學生開 Pages 網址即可使用。

學生可以直接開 [課堂網站](https://line-follower-2627.pages.dev/) 或 [感測板近鏡](https://line-follower-2627.pages.dev/?view=sensor)。實驗數據可用「匯出 CSV」下載，保留最近 15 分鐘嘅模擬時間、PID 設定、八路感測值及左右輪速。重設實驗會清除今次記錄。


## 公開原始碼與部署

正式網站：https://line-follower-2627.pages.dev/

物理引擎使用 MuJoCo 4.0.1 的 WebAssembly，3D 顯示使用 Three.js 0.187.0。PID 控制器及虛擬反射感測器由本專案 JavaScript 實作。Vite 負責打包，Cloudflare Pages 提供靜態網站託管，AI 試跑透過瀏覽器 Web Worker 搜尋 PID 參數。公式使用 KaTeX，教學圖由 Manim Community Edition 產生。

執行檢查：

```sh
npm test
npm run build
```

如要部署到自己的 Cloudflare Pages，修改 wrangler.jsonc 的專案名稱，再使用已登入的 Wrangler 執行 pages deploy dist。憑證由本機登入管理，請勿提交 .env、API token 或 Wi-Fi 密碼。Arduino 範例的學校 Wi-Fi 欄位保留空白，機械圖、教材及校徽包含於此公開專案，第三方元件授權見 public/licenses。公開原始碼未另授予學校標誌或教材的再授權。
