Arduino 範例同程式庫

用課堂 ESP32 範例配合兩個程式庫，對照實車點樣讀八路探頭，同埋點樣將 PID 修正送去 M3、M4。

  • 01_Digital_States.ino原裝感測器讀數範例
  • 02_Analog_Thresholds.ino八路反射讀數同板內門檻
  • Line_Follower_main.ino循線 PID 範例
  • LineFollowerLearn8CH.zip八路感測板程式庫
  • MotorEncoderBoard.zip編碼摩打板程式庫
預覽 Arduino 程式

喺 Arduino IDE 開啟

  1. 用 Boards Manager 安裝 Espressif Systems 嘅 esp32，揀 ESP32 Dev Module。
  2. 喺 Sketch → Include Library → Add .ZIP Library… 逐個揀上面兩個 ZIP。
  3. 開啟 Line_Follower_main.ino。如果 IDE 提示建立同名資料夾，揀同意，然後撳 Verify 編譯。
  4. 實車運行時，用 115200 baud 開 Serial Monitor，讀取呢部車今次開機嘅 Wi-Fi 名稱、密碼同控制網址。

範例用 TT 摩打模式，M3 接左輪，M4 接右輪。實車範例保留失線搜線。網頁嘅零增益示範會略過搜線，方便觀察直行甩線。
